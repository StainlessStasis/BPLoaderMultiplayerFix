# BPLoaderMultiplayerFix
A small patch for [Blueprint Loader](https://www.nexusmods.com/minecraftdungeons/mods/111) which fixes multiplayer related issues. This mod was made for [LetMeMove](https://www.nexusmods.com/minecraftdungeons/mods/245); I can't say how well it will hold up for other mods. It still has some issues, but it makes LMM work at the very least

# Installation & Dependencies
Along with this mod, you'll need [Blueprint Loader](https://www.nexusmods.com/minecraftdungeons/mods/111). To install mods:
1) Locate your game's local files. On Steam, right click on it -> `Manage` -> `Browse local files`. If you own the game through the MC launcher then idk, look it up.
2) Navigate to `Dungeons/Content/Paks`.
3) If you don't already have a mods folder, make one in this Paks directory, and name it EXACTLY `~mods` - tilda included!
4) Download the latest release, unzip it, and drop the `.pak` file into that ~mods folder.
